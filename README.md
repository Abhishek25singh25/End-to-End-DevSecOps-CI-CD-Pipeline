# 🚀 END TO END DEVSECOPS PIPELINE

Node.js Task Manager App used for building a complete DevSecOps CI/CD pipeline.

## Features
- REST API
- Simple UI
- Docker support
- Health check endpoint
- Unit testing (Jest)

## Run Locally
npm install
npm start

## Docker
docker build -t task-manager .
docker run -p 5000:5000 task-manager
